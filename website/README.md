# SHUFFL website

Static, responsive marketing site for SHUFFL. It is intentionally framework-free so it can be previewed or hosted directly from this folder.

Pages:

- `index.html` — product overview with auto-swapping image hero
- `about.html` — SHUFFL story and values
- `features.html` — product capabilities
- `contact.html` — contact details and form
- `policy.html` — community, venue, and safety policy
- `privacy.html` — plain-language privacy overview
- `terms.html` — terms of service overview
- `how-it-works.html` — the daily vibe → venue → group plan loop
- `vibes.html` — the vibe/archetype library
- `for-friends.html` — hosting and joining group nights

Preview locally from this folder with any static server, for example:

```powershell
python -m http.server 4173
```

The “Open the app” links point to the existing `../mobile` app folder.

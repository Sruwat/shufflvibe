PLAIN-LANGUAGE GUIDE

How the venue database works.

A simple operating guide for anyone managing SHUFFL venues.

01

Find venues

Use Sync pipeline to bring configured area-list, Google Places and OSM results into the canonical store.

02

Understand one venue

Open Preview for live identity, evidence, scores, hours and source health.

03

Make a change

Use Edit, save a draft, preview it, then publish only when the evidence is ready.

04

Add or import

Use Add venue for one place or Import Excel for a workbook or CSV.

05

Verify when ready

Keep evidence gaps visible. Unknown never becomes verified by accident.

06

What is live?

Google display fields are fetched at preview time and are not permanently copied into the venue record.

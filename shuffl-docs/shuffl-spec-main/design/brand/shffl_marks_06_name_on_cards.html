SH:FFL · the name on the cards

The name stops sitting beside the mark and goes inside it. Two things fight you: the cards are tilted, so the type tilts with them, and FFL is three characters where SH is two, so the cards cannot be the same size unless one of them carries slack. Both cards are built to fit FFL here, which leaves SH with air — the alternative is two cards of different widths, and two different-sized cards stop looking like a deck.

1 · TYPE TILTS WITH THE CARD
The honest version — the letters are printed on the cards, so they move with them. Twenty degrees is about the limit before the name stops reading as a name and starts reading as decoration.
2 · TYPE STAYS UPRIGHT
The name stays level and the cards tilt under it. Far easier to read — and the letters stop belonging to the cards, which is the whole point of putting them there. Pick this only if legibility beats the idea.
3 · LESS TILT, BIGGER TYPE
Ten degrees instead of twenty, cards larger, type up to 48. The name reads first and the tilt still says the cards are going. The trade is motion — at ten degrees the speed lines are carrying it almost alone.
3 ON LIGHT
Works, and the colon is now the only thing that is not a letter — which arguably makes the spelling clearer than the original wordmark did.
THE CATCH — THIS CANNOT BE THE ICON
Left: the lettered version at 64px. The type is mud. Right: the plain B mark at the same size, which is fine.
So this is a wordmark, not a logo system. It replaces the lockup and you still need the textless mark underneath it for the app icon, the favicon, the avatar and anywhere under about 120px. That is not a problem — most brands run exactly that pair — but it is two assets rather than one.
